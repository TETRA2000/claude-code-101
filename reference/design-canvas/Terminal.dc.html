Hidden files hold the keys

A terminal is a window where you type commands instead of clicking. Claude Code uses the same commands, just faster.

Click the commands on the right. Watch what ls shows, and what it hides.

Key idea A name starting with a dot, like .env or .ssh, is hidden. Hidden files often hold passwords and keys. You can't see them at a glance, but Claude can read them.
