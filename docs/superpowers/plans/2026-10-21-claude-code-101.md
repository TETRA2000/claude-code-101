# Claude Code 101 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, bilingual (EN/JA) web course that teaches non-engineers how Claude Code works and how to stay safe with it. It ships 5 complete units of Learn cards and scripted simulations, plus 6 "Coming soon" units on the map.

**Architecture:** A Vite + React single-page app with no backend. Course content is typed JSON under `content/`. Every learner-facing string is a `{ en, ja }` pair, and a validator test enforces the spec's content rules. The quiz engine is a pure reducer adapted from cascade-learn. A session holds its unit's items, so the engine is tested against a fixture unit, independent of the real content. Progress lives in `localStorage`.

**Tech Stack:** Node 24.5.0, Vite 8, React 19, TypeScript 7.0.2, CSS Modules, Vitest 5 + Testing Library, Playwright 1.63, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-21-claude-code-101-design.md`. Read it before any task. Mockups: `reference/design-canvas/*.dc.html`. Read them as a layout and behavior spec only; never port their runtime. Where they disagree with the spec, the spec wins.

**Reference code:** cascade-learn. Clone it once with `git clone --depth 1 https://github.com/TETRA2000/cascade-learn "$TMPDIR/cascade-learn"`. Tasks below say which of its files to copy or adapt.

## Global Constraints

- Every learner-facing string is a `Localized` (`{ en: string; ja: string }`), and both values are non-empty. English is written first. Japanese is a full, natural translation, with no review step.
- Commands, file paths, code, URLs, tool names and terminal output are never translated. They live in plain `string` fields.
- UI strings live in `src/i18n/ui.ts`, typed so a missing Japanese key fails `tsc`. Components never hard-code learner-facing text. Lesson text lives only in `content/*.json`.
- Language default: the stored choice, else `ja` if the browser's first language starts with `ja`, else `en`. Keep `<html lang>` in sync.
- No real AI, no command execution, no network requests except loading the site and Google Fonts (Bricolage Grotesque, DM Sans, JetBrains Mono, Noto Sans JP).
- Content safety:
  - Fake secrets contain `FAKE`.
  - URLs use reserved hosts (`*.example`, `example.com|net|org` and subdomains, `*.test`, `*.invalid`, `localhost`) or the real-host allowlist in `src/content/hosts.ts`.
  - There are no copy buttons anywhere.
- Rules: `HEARTS_PER_RUN = 5`, `XP_FIRST_TRY = 10`, `XP_RETRY = 5`, `XP_HINT_COST = 5` (taken off that item's award, never below 0), `ACTIVATION_GUARD_MS = 350`.
- Ready units have 3–5 Learn cards and 8–12 practice items. Every ready unit has `lastChecked` (`YYYY-MM-DD`) and at least one source URL.
- Design tokens are copied from cascade-learn's `src/styles/tokens.css`. Accessibility:
  - real `<button>`s, `aria-pressed` on selectable tiles, `aria-live` feedback, `role="progressbar"` with values;
  - targets ≥44px, contrast ≥4.5:1;
  - right/wrong shown with icon and text, not color alone;
  - `prefers-reduced-motion` respected.
- Laptop first, but no horizontal page scroll at 390px width. Long commands and URLs wrap (`overflow-wrap: anywhere`).
- Each item says which app it shows: `surface: 'terminal' | 'desktop'`. Unit 3 recommends the default "ask before acting" mode. Turning permissions off is always wrong in setup items.

## Review Focus

1. **Language switched mid-practice:** the run keeps its position, hearts, XP and selection, and only the text changes. Test: Task 11.
2. **Stored progress is corrupt, from another app, or storage throws:** the app starts with empty progress and never crashes. Test: Task 5.
3. **Long unbroken commands and URLs at phone width** (`curl -s https://… -d @.env`, `collect.example/?d=…`) in both languages: no horizontal page scroll. Test: Task 19.
4. **A double click on Check or Continue** must not skip an item or grade twice. Test: Task 11.
5. **A stored language that's invalid, or a browser reporting no languages:** fall back to `en`. Test: Task 3.
